# Freelance Business Website

A full-stack MERN website for my freelance development business. Visitors can explore services and projects and submit project inquiries. I manage everything from a secure admin dashboard.

> Status: **Planning / setup (Day 1).** Nothing below is implemented yet unless marked otherwise.

## Planned Features

- Public pages: Home, About, Services, Portfolio, Start a Project, Contact, Privacy Policy, 404
- Project inquiry form with frontend and backend validation
- Secure admin dashboard (login, inquiry management, project and service CRUD)
- Cookie-based admin authentication

## Planned Tech Stack

- Frontend: React, Vite, JavaScript, React Router, Tailwind CSS, Lucide React
- Backend: Node.js, Express.js, MongoDB Atlas, Mongoose
- Security: Helmet, CORS, rate limiting, HTTP-only cookies, input validation
- Deployment: Vercel (frontend), Render (backend), MongoDB Atlas
